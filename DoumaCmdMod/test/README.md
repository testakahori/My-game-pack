# 実 Forge のギフト検証

専用の使い捨てワールドで、実際のクライアント位置・エンティティ出現・ブロック・天候を検証します。通常のワールドでは実行しないでください。約6分かかります。

1. Java 17 で DoumaCmdMod を build し、Minecraft 1.20.1 / Forge 47.3.0 の検証専用サーバーへ最新版の JAR と bridge/commands をコピーします。
2. フラットワールドのレイヤーは底から bedrock 1、stone 24、dirt 3、grass_block 1（地面上 Y=-35）。server-ip=127.0.0.1、server-port=25587、rcon.port=25588、enable-rcon=true、online-mode=false、allow-flight=true、view-distance=6 を検証環境だけに設定します。EULA は内容確認の上で同意してください。
3. サーバールートに gift-qa-marker.json を作り、内容を {"purpose":"disposable-gift-effects-test"} にします。Java に -Ddoumacmd.bridgePort=25578 を指定して起動します。
4. このディレクトリで npm ci を実行します。環境変数 GIFT_QA_SERVER に検証サーバールートを設定して npm test を実行します。

--weather-only は氷河期・暴風雨・晴れ・天変地異だけ、--jumps-only はジャンプ3条件だけを実行します。結果JSONはサーバールート、または GIFT_QA_OUTPUT に出力します。検証後はサーバーを stop してください。

確認項目: 1個32ブロック／10個320ブロック／空中10回の加算、天空トラップの下降速度、アンビル100・鶏200・メテオ100・火山50、ゾンビ4種類各50（ゾグリンなし）、四方の矢240、48ブロック上の洪水、2分後も残る氷、天候サイクル停止時も3分で止まる雨、強制晴れ、天変地異のTNT100・ゾンビピグリン50・ウィザー1。

追加の地形攻撃テスト: 同じ環境変数を設定して `node terrain-attacks.cjs` を実行します。専用ワールドの別地点に検証用の地面を作り、アンビル100個の山と脱出阻止、氷の拘束・継続ダメージと脱出後の停止、深い地震穴への落下と溶岩、洪水のドラウンド30体、ゾンビ4種類各50体、火山50発と21×21の溶岩床、保護エリア内での攻撃抑止を確認します。

v1.0.35 の追加検証（`--v135-only`）:

- 氷河期: 5×5×3＝75ブロックが頭上から落ち、中心と外側で凍結・ダメージを受ける。脱出すると継続ダメージが止まり、氷は残る。`--ice-only` で単独実行できる。
- 流星群: 50塊×50ブロック＋破片500個（5素材それぞれ600個）。斜めの移動、炎と光、25回の爆発、クレーター、プレイヤーへの命中、5素材すべての残骸を確認する。
- 洪水: 水が6秒以内に到着し、ドラウンド30体＋海の生き物153体がすべて水中に出現する。出現後も8割以上が水中にいることを確認する。
- 天変地異: 深い地割れと溶岩に加え、流星群3000ブロックを確認する。
- ウィザー: 近くに羊がいてもサバイバルのプレイヤーを狙って弾を発射し、体力が減ることを確認する。
- 重力反転: 浮遊中の前進距離が通常の浮遊の60%未満になることを確認する。
- 保護エリア内の攻撃抑止も再確認する。

`--new-effects-only` は流星群・洪水・天変地異の3項目、`--cataclysm-only` は天変地異のみ実行する。実測結果は terrain-attacks-results.json に出力する。
