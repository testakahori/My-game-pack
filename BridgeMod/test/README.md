# 実 Forge のギフト検証

## 大量いいねとギフトの同時処理

`node like-load.cjs` は、下記の専用サーバーと同じマーカー・ポート・環境変数を使います。テスト開始時はプレイヤーを接続せず、最新版のBridgeMODとコマンドを配置してください。テスト自身がクライアントを接続します。使い捨てワールドに水槽を作り、テスト用コマンドを追加するため、普段のワールドでは実行しないでください。

- いいねの待ち列120件を満杯にし、121件目を429で返すこと、既存の120件を削除しないこと。
- 共通イベントは同じeventIdで再送しても届いた分を実行すること。ゲーム固有要求の再送抑止はgame-integration.cjsで別に検証する。
- タラが残っている間に20件のギフトを順に発動し、全員の名前付きゾンビを召喚すること。
- タラ120匹分をすべて順番どおりに実行し、同時に存在するいいね由来のタラが64匹を超えないこと。
- いいね由来のタラは約20秒で消え、ギフト由来の魚・元からいる魚は残ること。
- 失敗数、サーバー平均tick時間、TPS、ギフトの発動確認までの待ち時間を記録すること。

結果はサーバールートの `like-load-results.json` に保存します。終了後に検証サーバーを停止してください。

専用の使い捨てワールドで、実際のクライアント位置・エンティティ出現・ブロック・天候を検証します。通常のワールドでは実行しないでください。約6分かかります。

1. Java 17 で BridgeMod を build し、Minecraft 1.20.1 / Forge 47.4.10 の検証専用サーバーへ最新版の JAR と bridge/commands をコピーします。
2. フラットワールドのレイヤーは底から bedrock 1、stone 24、dirt 3、grass_block 1（地面上 Y=-35）。server-ip=127.0.0.1、server-port=25587、rcon.port=25588、enable-rcon=true、online-mode=false、allow-flight=true、view-distance=6 を検証環境だけに設定します。EULA は内容確認の上で同意してください。
3. サーバールートに gift-qa-marker.json を作り、内容を {"purpose":"disposable-gift-effects-test"} にします。Java に -Dbridgemod.bridgePort=25578 を指定して起動します。
4. このディレクトリで npm ci を実行します。環境変数 GIFT_QA_SERVER に検証サーバールートを設定して npm test を実行します。

--weather-only は氷河期・暴風雨・晴れ・天変地異だけ、--jumps-only はジャンプ3条件だけを実行します。結果JSONはサーバールート、または GIFT_QA_OUTPUT に出力します。検証後はサーバーを stop してください。

確認項目: 1個32ブロック／10個320ブロック／空中10回の加算、天空トラップの下降速度、アンビル100・鶏200・メテオ100・火山50、ゾンビ4種類各50（ゾグリンなし）、四方の矢240、48ブロック上の洪水、2分後も残る氷、天候サイクル停止時も3分で止まる雨、強制晴れ、天変地異のTNT100・ゾンビピグリン50・ウィザー1。

追加の地形攻撃テスト: 同じ環境変数を設定して `node terrain-attacks.cjs` を実行します。専用ワールドの別地点に検証用の地面を作り、アンビル100個の山と脱出阻止、氷の拘束・継続ダメージと脱出後の停止、深い地震穴への落下と溶岩、洪水のドラウンド30体、ゾンビ4種類各50体、火山50発と21×21の溶岩床、保護エリア内での攻撃抑止を確認します。

v1.0.35 の追加検証（`--v135-only`）:

- 氷河期: 5×5×3＝75ブロックが頭上から落ち、中心と外側で凍結・ダメージを受ける。脱出すると継続ダメージが止まり、氷は残る。`--ice-only` で単独実行できる。
- 流星群: 50塊×50ブロック＋破片500個（5素材それぞれ600個）。斜めの移動、炎と光、25回の爆発、クレーター、プレイヤーへの命中、5素材すべての残骸を確認する。
- 洪水: 水が6秒以内に到着し、ドラウンド30体＋海の生き物153体がすべて水中に出現する。出現後も8割以上が水中にいることを確認する。
- 天変地異: 深い地割れと溶岩に加え、流星群3000ブロックを確認する。
- ウィザー: 近くに羊がいてもサバイバルのプレイヤーを狙って弾を発射し、体力が減ることを確認する。
- 重力反転: 浮遊中の前進距離が通常の浮遊の60%未満になることを確認する。
- 保護エリア内の攻撃抑止も再確認する。

`--new-effects-only` は流星群・洪水・天変地異の3項目、`--cataclysm-only` は天変地異のみ実行する。実測結果は terrain-attacks-results.json に出力する。

## v1.0.42 流星群

`node terrain-attacks.cjs --meteor-only` で単独検証します。直径約7ブロック・109ブロックの岩球50塊＋破片500個（合計5950個、各素材1190個）、横移動が下降の1.6倍以上の浅い軌道、プレイヤーへの命中、25回の爆発、5素材の残骸を確認します。通常の昼から発動中は夜18000、終了後は昼1000へ戻ることも実 Forge で確認します。

## 固定環境と敵モブだけの自然発生停止

Java 17でBridgeModの通常のbuildに加えて、明示的に `environmentProbeJar` タスクを実行します。通常の配布JARには検証コードは含まれません。Forge 47.4.10の使い捨てサーバーへBridgeMODと `build/qa/environment-probe.jar` を配置し、上記と同じマーカー・ポート・GIFT_QA_SERVERを設定して `node fixed-environment.cjs` を実行します。DisplayMODと通常のbridge/commandsも配置してください。

- sendCommandFeedback・commandBlockOutputがfalseで、手動でtrueへ変えても固定値へ戻る。
- doMobSpawningはtrueのままで、動物と魚の自然発生を妨げない。
- 通常世界とネザーの160条件で、敵の自然発生・生成時出現・巡回・増援を止め、牛・羊・タラとコマンド・卵・スポナー・ゲームイベントの出現を許可する。
- 村への自動ゾンビ襲撃を止める。
- 召喚済みの敵を後から削除しない。
- 実際のギフトHTTP経路から、送信者名付きゾンビとタラを召喚できる。

出現種別を指定してForgeの実際のEntityType.spawn／イベントバスを通す検証です。自然発生を長時間待って確率を測るテストではありません。結果はサーバールートのfixed-environment-results.jsonへ保存します。

## ゲーム連携の再送・リセット・表示時間

`environmentProbeJar`には配布しない`gameprobe`も含みます。専用の使い捨てForge 47.4.10サーバーへ配置し、同じGIFT_QA_SERVERを指定して `node game-integration.cjs` を実行します。count=150の無分割転送、別送信者の分離、待機中と実行済みの再送抑止、3キューの旧要求失効、遅延再送、一時停止、終了、引数検証、実開始時だけのタイトルと0/120/20 tickの表示パケットを検証します。DisplayMODなしの専用起動ではGIFT_QA_NO_DISPLAY=1を指定します。

## 保護ブロック（コマンドブロック3種）

`node protected-blocks.cjs` は、妨害のコマンドでコマンドブロックが置き換えられても、同じ向き・同じコマンドで残ること、常時実行のインパルス型が再実行されないこと、リピート型が動き続けることを確かめます。上と同じマーカー・ポート・GIFT_QA_SERVER に加えて、server.properties に `enable-command-block=true` が必要です。

- BridgeMOD の分（`--bridge-only`）：lavafloor・husk_watertower・`/bridge/exec` の fill、同じ種類のコマンドブロックでの上書き、プレイヤーから遠い forceload のチャンク、火山の溶岩の床でも壊せないブロック（バリア・エンドポータルの枠）が残ること（BridgeMOD 1.7.1 から）。
- 採掘の分（`--saikutu-only`）：SaikutuMOD を入れたサーバーで実行します。テストが `bridge/commands/minecraft/game_saikutu_*.txt` を書きます。TNT大爆発は、頭上の TNT が置かれたらすぐ片付けます（SaikutuMOD 1.1.0 から、待つと足元の TNT が連鎖を始める）。

結果はサーバールートの `protected-blocks-results.json` に保存します。

## 強さの上限なし（2026-10-11）

`node no-limits.cjs` は、上限をやめたことを確かめます。上と同じマーカー・ポート・GIFT_QA_SERVER を使います。

- BridgeMOD の分（`--bridge-only`）：鶏の雨 count=5 が1000羽になる。スーパージャンプ count=20 が640ブロック上がり、低速落下が付かない。
- 採掘の分（`--saikutu-only`）：SaikutuMOD を入れたサーバーで実行します。TNT大爆発 count=2 の衝撃波の穴（コマンドブロックと壊せないブロックは残る）、洪水 count=5、木 count=210、TNT大爆発 count=1000 が調べる範囲をえぐり終えたら終わること。穴を爆心から100ブロック先まで測るので、server.properties の `view-distance=10` にしておきます（6だと端のチャンクが読み込まれない）。テストが `bridge/commands/minecraft/game_saikutu_*.txt` を書きます。

結果はサーバールートの `no-limits-results.json` に保存します。
