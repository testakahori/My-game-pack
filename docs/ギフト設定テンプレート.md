# ギフト設定を保存・読込する

「ギフト設定」→「ギフトの割り当て」の上部から操作します。ゲームごとの設定を切り替えたり、同じアプリを使う人に配布したりできます。

1. ギフトにコマンドと実行回数を登録します。
2. 「ギフト設定保存」を押し、「ダイヤ集め用.json」など用途がわかる名前で保存します。現在保存済みの割り当て全件を、1つのJSONファイルへ保存します。
3. 切り替えるときは「ギフト設定読込」でJSONを選びます。ギフト・コマンド・回数の一覧を確認します。この時点では設定は変わりません。
4. 「この内容を適用」を押すと、現在の割り当て全件を読み込むファイルの内容で置き換え、通常のギフト設定にも反映します。一覧にないギフトの以前の割り当ては外れます。キャンセルすれば変更しません。

適用直前の設定は自動でバックアップします。元に戻すには「運用センター」の設定バックアップから適用前の世代を選んで復元します。バックアップの復元はギフト以外の設定にも及ぶので、作成日時と内容を確認してください。

## 配布するとき

保存したJSONだけを渡してください。ギフトID・ギフト名・コマンドのファイル名・実行回数と、保存名・作成アプリのバージョン・作成日時が入ります。TikTokアカウント、RCONパスワード、サーバーの保存先は含みません。

コマンドのファイル本体は含まれません。配布先に同じコマンドが必要です。必要なコマンドがない場合は名前を表示し、適用を止めます。独自コマンドを使う場合は、必要なアプリのバージョンやコマンドを配布時に案内してください。

ギフト設定の読込ではアカウント・接続設定・いいね等のイベント設定・保存した配信画像を変えません。コマンドも発火しません。配信画像の表示も合わせる場合は、配信画像メニューで別途編集してPNGを保存し直してください。

未保存の入力がある場合は破棄の確認が出ます。割り当ては1〜1000件、実行回数は1〜100回、ファイルは2MBまでです。不正な形式・重複ID・読込中の設定変更は適用前に検出します。
