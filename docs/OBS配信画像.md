# OBS用の配信画像を作る

左メニューの「配信画像」から作成できます。MinecraftやTikTokに接続せずに編集できます。

1. 「ライブグリッド」「クリアカード」「ナイトステージ」から見せ方を選びます。
2. 「設定済みをまとめて追加」でギフトと効果名を取り込みます。個別のギフトを検索して追加することもできます。
3. プレビューのカードを選ぶと、表示名・回数・グループ・個別色を変更できます。「コマンド設定」からゲーム内のコマンドと実行回数も編集できます。
4. 「色・配置」で全体の色、グループ別の色、枠／背景、列・段を調整します。デザイン名と見出しも入力できます。
5. 「PNGを保存」で書き出します。OBSの「ソース」→「＋」→「画像」でPNGを選び、位置とサイズを調整してください。

上段のギフト一覧と下段のルール案内を分ける場合は、「新しく作る」で別々のデザインを作り、2枚のPNGとして配置します。白地カードも表示文を自由に変更できます。現バージョンのカード画像はギフト一覧から選びます。

縦9:16／横16:9のプレビューで上下の置き方を確認できます。ゲーム映像の案内領域はPNGに含まれません。PNGの余白は透明です。

編集内容はこのPCに自動保存されます。「保存したデザイン」で切り替えられます。編集中の操作は「画像を元に戻す」「やり直す」で戻せます。操作履歴は画面を閉じると終了します。PNGの再編集ではなく、保存したデザインから編集してください。

画像を読み込めない場合やカードが枠からはみ出す場合は保存を止め、画面に解決方法を表示します。最大20デザイン、1画像につき96カードです。

保存ダイアログのタイトルは「ギフト案内画像を保存」。ファイル名にはデザイン名と画像サイズが入り、例は「ギフト案内_1080x680.png」です。

OBS公式: [画像ソースと透過PNG](https://obsproject.com/kb/image-sources) / [ソースの追加](https://obsproject.com/kb/sources-guide)

## 登録済みギフトとコマンドを編集する

下の「ギフト・コマンド」一覧で、ギフトの「コマンド設定」を押してください。プレビューのカードを選び、左の「コマンド設定」から開くこともできます。

- コマンドと、ギフト1個あたりの実行回数（1〜100回）を選び、「コマンド設定を保存」を押します。通常の「ギフト設定」にも反映されます。保存だけではゲーム内のコマンドを発火しません。
- 「この画像の効果名・回数も更新」がオンなら、編集中の画像にある同じギフトの表示をそろえます。色・配置・独自のグループ分けは保ちます。別の保存済みデザインは変更しません。
- 独自の表示名を残す場合は、このチェックを外します。文字や色の直接編集は、これまでどおり画像だけの変更です。
- 画像の変更後はPNGを保存し直し、OBSで使用する画像を更新してください。「画像を元に戻す」は画像だけを戻し、保存済みコマンドは戻しません。
- 未登録のギフトも「すべて」で探し、同じ画面からコマンドを登録できます。ギフトの画像を押すと、画像にカードを追加します。

未保存のコマンド変更を閉じようとすると確認が出ます。保存に失敗した場合は入力を残します。他の操作で同じギフトが更新された場合は上書きせず、開き直しを案内します。

## カードを外す

プレビューの各カード右上にある「×」で、そのカードだけを画像から外せます。「画像を元に戻す」で取り消せます。ギフトとコマンドの登録は残ります。×ボタンは編集用で、保存するPNGには入りません。
