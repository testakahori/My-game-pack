# 配信演出（v1.0.28）

BOOTHなどで購入・配布されたローカル素材を登録して使う機能です。アプリ内の販売・課金・ポイント制度はありません。

## 最初の演出

1. 左メニュー「配信演出」を開き、「素材を登録」でPNG・音声・動画を選びます。
2. 「画像・動画」「声・BGM」を選び、条件を設定します。最初は100いいね・雑談用の位置と音量が入力されています。
3. 「保存して試す」を押すと確認用ウィンドウで再生します。素材単体の「試す」は最大10秒です。
4. 「OBS用URLをコピー」を押し、OBSのブラウザソースに貼り付けます。幅1920・高さ1080を指定します。
5. 配信中のTikTokアカウントを入力して「TikTokに接続」。ゲーム用Bridge起動中はその接続を使います。

素材を用意した状態なら、登録から最初の手動再生まで5分以内を目標にした導線です。OBS・TikTok側の初回設定や素材の購入時間は含みません。

## 条件とプロフィール

- いいね：保存したしきい値の倍数に到達したとき。接続後の最初の累積数を基準とし、接続前の分を大量再生しません。
- 指定ギフト：ギフト一覧またはギフトIDから指定します。
- コイン数：ギフト1個のコイン数、または同じ視聴者の連続ギフト合計が条件に初めて到達したとき。円換算ではありません。
- 雑談・マイクラ・歌の3プロフィールごとに条件と全体音量を保存します。位置・大きさ・個別音量もテンプレートから設定できます。
- 画像と音声を一緒に再生できます。動画自身に音がある場合、選択した追加音声も重なります。
- 実際の音量は「演出音量 × プロフィール音量」です。たとえば80% × 35% = 28%。
- 再生は設定秒数が上限です。音声・動画だけの演出は全素材の終了時に次の演出へ進みます。

## 常設の操作

- 演出を全停止：本番・プレビューの現在の演出と待ち行列を消去。次に届くイベントは通常どおり扱います。
- 音声を全停止：演出の音声を解除するまで消音。動画の映像は残ります。
- 演出を一時停止：再生を止め、再開で続きから再生。一時停止中の新しいイベントはため込みません。
- 演出設定を元に戻す：未保存の編集中内容、またはこの起動中の直近20回の演出設定変更を取り消します。Minecraft・読み上げの設定を戻すボタンではありません。

プロフィール・保存設定の変更時は以前の再生を停止します。待ち行列は最大20件、30秒以上待った演出は破棄し、急増したいいねを大量に後追いしません。手動テストは直前のプレビューテストを置き換えます。

## 録画・配信前

「映像・音声を試験」でバーの動きと短い確認音を確かめ、「映像が見えた」「音が聞こえた」を押します。確認は現在の起動・設定に対して記録され、配信前チェックにも表示されます。

プレビューとOBSは別出力です。OBS側でも「OBSで音声を制御する」、ミキサー、短い試し録画を確認してください。同じURLの重複登録は音が重なる原因になります。アプリが再生できても、スピーカー・OBSの最終出力が適切かは別途確認が必要です。

## 素材と保存場所

- 画像：PNG / JPEG / GIF / WebP
- 音声：MP3 / WAV / OGG / M4A
- 動画：MP4 / WebM（実際に再生可能なコーデックが必要。MP4 H.264/AACを検証）
- 1件300MB・一度に30件・登録300件・アプリ側の保存容量2GBまで。
- 登録時に原本をコピー。設定とコピー素材はユーザーデータ内のmedia-effectsフォルダーに保存されます。
- 設定の取り消しで素材の原本やコピーを消しません。素材フォルダーを移す場合はアプリ終了後に設定とassetsを一緒に保管してください。
- 出力は127.0.0.1の19639番ポート。OBS用URLにはローカル出力用のトークンを含むため、そのまま公開しないでください。
