# 自動更新のlocal版エラー修正（2026-10-03）

> 過去の自動更新方式の記録です。1.0.46以降は[手動配布](手動配布とアプリ更新.md)へ変更し、この更新経路は使用しません。

## 確認した原因

使用中の1.0.44-local.20261003で、運用センターに「No published versions on GitHub」が表示されていた。

electron-updaterはバージョンにプレリリース部分があるとallowPrereleaseを自動でtrueにする。GitHubProviderはlocalというチャンネルに一致するタグを探すが、公開済みの正式版には一致しないため、公開版があっても「公開版がない」というエラーになる。Nortonによるブロックが原因である証拠は、今回のエラーにはない。

## 修正

- allowPrerelease=falseを明示し、GitHubの正式版とlatest.ymlを確認する。
- allowDowngrade=falseを明示し、ローカル開発版より古い公開版へ戻さない。
- 更新確認Promiseだけが失敗した場合も、checkingのままにせずerrorへ戻して再試行できるようにする。
- 終了時の無条件インストールを止め、稼働確認付きの「更新を適用」からインストールする。
- ローカル版では正式版だけを確認する説明を表示。「最新」と断言する表示は「利用できる新しい公開版はありません」へ変更。

## 検証

本物のGitHubProviderを使う回帰テストで、旧設定のエラーと修正設定の取得成功を再現。

実際のGitHubに対し、releases.atom・releases/latest・v1.0.43/latest.ymlの3件がHTTP 200。取得した正式版は1.0.43で、1.0.44-local.20261003より古いため更新対象外。実ネットワーク検証ではインストーラーのダウンロード・インストールは行っていない。

リリース一覧：https://github.com/testakahori/My-game-pack/releases

## 適用状況

ソース修正のみ。使用中のアプリを入れ替えていないため、そのアプリでは同じエラー表示が残る。次回許可されたアプリ更新で反映する。新規GitHub Release・タグ・更新資材の公開は今回行わない。
