# Euler StreamのAPIキー設定

配信ホームの「TikTok 接続設定」にある「Euler Stream APIキー」を開いて設定します。キーの設定は任意です。

1. 「公式サイトでキーを取得」からEuler Streamを開き、自分のアカウントでAPIキーを取得します。
2. アプリへ戻り、キーを貼り付けて「キーを保存」を押します。
3. BRIDGEが動いている場合は、配信への影響がないタイミングで「BRIDGEを再起動して適用」を押します。停止中なら、次にBRIDGEを起動したときに適用されます。

配信状態の確認とギフト一覧の更新には、保存後の次の取得から適用されます。すでに取得中の処理は、その処理を開始した時点の設定を使います。

「保存しました」はPCへの保存完了です。有効なキーかどうかや、接続できるかどうかを保証する表示ではありません。接続後はホームのTikTok接続状態を確認してください。

キーはWindowsの暗号化機能を使い、アプリ専用の保存先に保存します。保存済みのキーを画面へ読み戻すことはありません。通常の設定バックアップ、ギフト設定の保存、配布ファイルには含めません。別のPCへ移る場合は、改めてキーを設定してください。

キーを変更するときは、新しいキーを入力して保存します。「削除」を押すとキーなしの接続方法へ戻ります。BRIDGEが動いている場合は、削除後も再起動して適用してください。

Euler Streamには無料のCommunityプランがあります。利用上限や対応するAPIはプランによって異なるため、最新の条件は[公式料金ページ](https://www.eulerstream.com/pricing)で確認してください。キーを保存しても有料プランへの申し込みは行われません。

## 開発時の確認（2026-09-27）

- 使用するTikTok-Live-Connectorを2.4.3から2.5.0へ更新し、依存バージョンを固定。
- [2.4.3から2.5.0の公式差分](https://github.com/zerodytrash/TikTok-Live-Connector/compare/v2.4.3...v2.5.0)を確認。署名サービスの回数制限に関する応答ヘッダー保持などの修正を取り込み。
- アプリから渡したキーを、BRIDGE・配信状態確認・ギフト取得の各プロセスが`signApiKey`として利用。キーをコマンドライン引数や通常の設定JSONへ書かない。
- コネクターが返す`retryAfter`の単位はミリ秒。再接続ではこの待ち時間を尊重。
- いいね・ギフト・コメント・フォロー・シェア・訪問・未設定ギフトは、現行protobufを通す模擬受信テストで確認。
- Electronの実画面とWindowsのsafeStorageで、テスト用キーの保存・再表示・削除を確認。実際に発行されたキーを使ったLIVE接続は未検証。
- ユーザーの指示により、アプリのバージョン変更・リリース公開・インストール済みアプリの更新は保留。
