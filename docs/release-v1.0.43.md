# v1.0.43

- 流星群は巨大な岩を2塊ずつ同時に流し、次のペアが続きます。5素材各10塊（1塊109ブロック）と破片2500個。岩全体の位置・速度を同期し、浅い斜め軌道・炎と光の尾・夜から昼への復帰・直撃・クレーター・残骸を維持します。
- ギフト設定のコマンド選択にカテゴリ別の表示と名前・効果の検索を追加しました。絞り込んでも保存済みのコマンドは消えません。
- 配信統計は1配信ごとの履歴を常時表示。受信したギフト個数・コイン相当・いいね等を記録し、7日・30日で比較します。コマンドが未設定・無効でも受信統計へ含めます。
- TikTokで確認した受取額を任意で入力できます。コインから固定換算せず、未入力と0円を区別します。入力途中の画面切替も保護します。
- 個別・全履歴のMD出力を更新。過去に記録していない数字は未取得と表示し、今後の受信統計は30日を超えて保持します。

検証: 型チェック・Viteビルド、Bridge14件＋App127件。本番Connectorのprotobufから統計保存までの結合テスト。分離Electronの実レンダラーで履歴・比較・受取額・未保存保護・MD・カテゴリ検索を操作。使い捨てForgeで7950ブロック、同時移動最大436ブロック、25爆発、直撃ダメージ・残骸・夜18000→昼1000を確認しました。実際のTikTok配信への投稿操作はしていません。
