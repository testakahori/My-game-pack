# v1.0.33 ギフトコマンド強化

- 洪水: 48ブロック上に25×25の水源。
- 弾丸タイム: 全方向から240発の矢が飛来。プレイヤー・友好Mob・敵を区別せず狙う。
- 空からアンビル100個、鶏200匹、メテオ100発、火山50発。
- 天空トラップ: 上空85ブロックへ移動して急降下。
- スーパージャンプ: 自動で32ブロック上昇。10個なら320ブロック、空中で追加されたギフトも加算。
- ゾンビ総襲撃: ゾンビ・ハスク・ドラウンド・村人ゾンビ・ゾグリンを各50体。
- 氷河期: 97×97の地表を凍結。暗闇・猛吹雪は約2分、氷は残す。
- 暴風雨: 天候サイクルを止めたワールドでも約3分で終了。「強制晴れ」を追加。
- 天変地異: 雷20発、雨、大地の亀裂、41×41の頭上マグマ、猛吹雪、TNT100発、ウィザー1体、ゾンビピグリン50体。
- 砂落下を1種類へ統合、竜巻を削除。旧割当はバックアップして移行。
- ルーレット: 約0.05秒で高速切替、最後だけ減速。
- Forgeボタンは常に「Forgeをインストールする」。インストーラーの「Install client」へ案内。

大量召喚は短時間に分けて実行します。破壊系コマンドはワールドを変更します。

## 似たコマンドの違い

- 暗黒: 15秒の Darkness と Blindness に、ウォーデン／洞窟の音と黒い粒子。暗闇地獄: 15秒の Blindness のみ。
- 愛犬が来た！: プレイヤーになついたオオカミ1匹。ペット召喚: オオカミ2匹＋猫1匹、骨8個＋生鱈8個で手なずける。

## 検証

Bridge14件・Electron53件、型チェック・UIビルド、Forge Modビルド成功。専用Forgeサーバーへ実クライアントを接続して、召喚数・ジャンプ高さ（1個／10個まとめ／10回連続）・急降下・洪水高度・氷の残存・2分／3分タイマー・複合コマンドを確認。ルーレットのタイトル29枚と平均約63msの高速切替を実通信で確認。通常のユーザーワールドで破壊系コマンドを検証していません。
