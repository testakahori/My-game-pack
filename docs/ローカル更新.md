# 公開しないローカル更新

2026-10-03に、アプリ1.0.44-local.20261003、BridgeMOD 1.3.5、DisplayMOD 1.0.0を手元のPCへ反映した。Minecraft 1.20.1 / Forge 47.4.10を使用する。公開版とは別のブランチに保管し、GitHub Releaseやタグは作成しない。

## 再作成

1. アプリのversionに `-local.` を含める。BridgeMODのjar名はゲーム切替機能が認識できる数字のバージョンにする。
2. 本体のnode_modulesは実フォルダーで用意し、package-lock.jsonから `npm ci --ignore-scripts` で構築する。別フォルダーへのリンクだと、electron-builderが本番依存を欠落させる場合がある。
3. 通常どおりフロントエンド、BRIDGEランタイム、BridgeMOD、DisplayMOD、サーバーテンプレートをビルドする。テンプレートはワールド・プレイヤー・パスワードを含まない配布用資材のみ。
4. `npm exec -- node scripts/package-local.cjs <出力先>` を実行する。スクリプトは公開しない設定を固定し、npm CLIを直接呼び出す。必要に応じてWindowsの信頼済み証明書ストアを利用するが、証明書検証やウイルス対策は無効化しない。
5. app.asarと同梱MODのID・バージョンを確認する。1.0.46以降のアプリ本体は手動更新のため、自動更新ランタイムと更新フィードを同梱しない。

## 反映時の確認

- Minecraftの保存終了、サーバー・BRIDGEの停止後に、旧アプリ・設定・MODを退避する。MAP保存履歴は自動作成しない。
- サーバーとMinecraftの両方で旧DOUMAMODを退避し、BridgeMODとDisplayMODを置く。意図して導入済みの他MODは保持する。
- アプリを起動して既存の保存先と初期構築済み状態、BRIDGEの同期バージョン、設定の一致を確認する。旧インストーラーの確認フラグが残っている場合は「もうすでにセットアップ済みです」で既存環境を検証する。
- 実際のMinecraft起動でMOD一覧を確認し、イベント負荷試験は隔離ワールドで行う。通常ワールドで破壊コマンドを試さない。
