# UIレビュー前のデザインへの復元

## 変更内容

利用者の指定により、PR #107 で行った全画面のデザイン変更を、直前の `e88ae9c` の状態へ戻した。共通CSSの追加、文字サイズ・配色・余白の上書き、保存バー、追加ボタン、ゲーム選択の折りたたみを取り消し、セットアップ完了ヘッダー画像と各画面の元の配置を復元した。`index.css`、`studio.css`、`main.tsx` は復元基準と一致する。

以下の不具合修正は保持した。

- セットアップのやり直しで既存サーバーフォルダーを消さない。開発ブラウザーでも既存セットアップの標準保存先を再検出する。
- 「もうすでにセットアップ済みです」の失敗・キャンセルをボタンの近くに表示し、確認中の別操作を抑止する。
- ゲーム保存前も配信ホームを表示する。保存前は起動操作だけを止め、停止操作は利用できる。
- 配信手順・ギフト情報の未確認状態を、完了や架空の値として表示しない。
- 編集再開後の古い保存成功表示を隠す。読み上げ用の操作名を保持する。

利用者が不要と指定した配信ホームの2つの説明文は削除したままとした。

## 検証

- `npm run verify` 成功（型チェック、Bridgeシミュレーション、アプリテスト386件、ビルド）。
- 新規回帰テスト5件は、`git archive` で取り出した修正前の `97accde` では5件とも失敗することを確認済み。
- 廃止した共通保存バー専用のテスト2件を削除。スイッチ名と配信手順の状態テストは保持。
- 最終デザインの実機・ブラウザー操作確認は、利用者の指示により実施しない。途中段階の実機スクリーンショットは最終状態の証拠として扱わない。
