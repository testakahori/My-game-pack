# 配信ワールドをゲームごとに（計画）

ユーザーの決定（2026-10-29〜30、「この計画で作る」）。

## ユーザーの言葉

- 「採掘は haihu_world フォルダにさえ入れておけば、自然生成される普通の MAP も、プレイヤーが自分で作った MAP も、私がイベント用に配布した MAP も使えるようにしたい」
- 「埋め立てを選んだ時、haihu_world には埋め立て専用の MAP（umetate_lab_map）一覧だけが現れるようにしてほしい」
- 「MOD のようにマップも切り替えてほしい」→ ゲームごとに、最後に使ったワールドを覚える（ユーザーの決定「ゲームごとに覚える」）
- 「まだ作ってないけど RUN も専用 MAP あるからね」

## 決まり

1. **使えるワールド**（`electron/game_maps.cjs` の `worldAllowed`。ワールドは `haihu_world/<名前>` の最後の名前で見る）
   - 専用マップ（games.json の `maps`）を持つゲーム（埋め立て。のちの RUN）：自分の専用マップだけ。
   - 専用マップの無いゲーム（今の RUN・選択肢に出さないサバイバル）と、専用でないワールドも使うゲーム（games.json の `"freeWorlds": true`。採掘）：自分の専用マップと、どのゲームの専用マップでもないワールド全部。
2. **「配信ワールド」の一覧**（`server:worlds:list`）：`haihu_world` の中のフォルダーのうち、今のゲームで使えるものだけ（`worldsForGame`）。
3. **切り替えるとき**：切り替える前のゲームが使っていたワールドを、そのゲームの分として覚える（profiles.json の `worlds`。そのゲームで使えるワールドのときだけ）。
4. **切り替えた先のワールド**（`planMapChange`）
   - 専用マップを持つゲーム：今までどおり（ほかのゲームから入る・初期化・使う場所に無いときは初期マップを写す。それ以外は level-name だけ合わせる）。
   - それ以外のゲーム：
     1. 切り替えたときで、そのゲームの分として覚えたワールドがまだあり、使えるなら、それに戻す。
     2. 無ければ、今のワールドが使えるなら、そのまま。
     3. 使えなければ「専用マップを持つゲームに入る前のワールド」（今の `mapReturnLevel`）。それも無ければ `haihu_world/world`。
   - 変わる所：マップの無いゲームどうしで切り替えたとき、直下に手で入れた `umetate_lab_map` を使っていたら、`haihu_world/world` へ移す（前は触らなかった）。
5. **2回目のレビュー（opus。重大 0・重要 2・軽い 10）を受けて決めたこと**（ユーザーの決定）
   - 重要1「あるものから選び、無ければそのまま」：4 の 3 の候補は実際にあるものだけ。haihu_world/world も無ければ haihu_world の中の、使える最初のワールド。1つも無ければ level-name を変えない（本物の配信サーバーは haihu_world が無く、直下の umetate_lab_map を使っていて、無いワールドを指すと次の起動で初期セットアップが外れた）。
   - 重要2「両方使えるように作る」：専用マップと freeWorlds を両方書いたゲームは、覚えたワールド → 今のワールド → 自分の専用マップ（無ければ写す）の順。「マップを初期化」は今が自分の専用マップのときだけ出す（list の `mapResettable`）。専用でないワールドで押すと理由を出す。
   - 軽い指摘は全部直した：大文字小文字と \ を同じに見る、同じゲームのまま保存し直したときは今の専用マップ・覚えたワールドを先に見る、配信ワールドの欄で一覧に無いワールドは選べない項目として見せる、ゲームの切り替え中は server.properties を書かない、開発用の画面も一覧を絞る、テストを足した。
6. **途中で止まったとき**：今の切り替えの途中の記録（`pending-switch.json`）で、前の level-name と profiles.json（`stateBefore`）に戻す。

## テスト（electron/test/game-maps.test.cjs ほか）

- `worldAllowed`・`worldsForGame`：埋め立てでは `umetate_lab_map` だけ。採掘では `umetate_lab_map` 以外の全部。採掘に専用マップを足したときは、それも出す。
- 採掘で `haihu_world/event` を選び、埋め立てをはさんで採掘に戻すと `event` に戻る。
- 採掘（event）→ RUN（other を選ぶ）→ 採掘は event、→ RUN は other（ゲームごと）。
- 覚えたフォルダーが消えていたら、上の 4 の 2・3 に戻る。
- 切り替えに失敗したら、前のワールドと記録に戻る。
- `server:worlds:list` は今のゲームで使えるものだけを返す。
